دليل شامل لمشروع صالون التجميل

هذا الملف مخصص لمراجعة الفريق وفهم تفاصيل المشروع قبل المناقشة.

1. فكرة المشروع والخدمات

الفكرة الأساسية: موقع ويب وتطبيق إداري لصالون تجميل نسائي. يهدف إلى أتمتة الحجوزات وإدارتها إلكترونياً.

  • للعملاء: إنشاء حساب، استعراض الخدمات، حجز المواعيد.
  • للإدارة: إضافة وتعديل الخدمات، ومتابعة الحجوزات والموافقة عليها.

2. التقنيات المستخدمة

  • الواجهة الأمامية: HTML, CSS, JavaScript, Bootstrap 5.
  • البرمجة الخلفية: لغة PHP 8 لمعالجة العمليات.
  • قاعدة البيانات: MySQL، واستخدمنا اتصال PDO للحماية القصوى.

3. جميع جداول قاعدة البيانات

قاعدة البيانات beauty_salon_db تحتوي على 5 جداول مترابطة بالكامل:

1. جدول customers (العملاء والمدراء)

الحقل الشرح
id مفتاح أساسي (Primary Key)
name الاسم الكامل للمستخدم
phone رقم الجوال (غير مكرر UNIQUE)
email البريد الإلكتروني للوصول للحساب (غير مكرر UNIQUE)
password كلمة المرور مشفرة
role يحدد نوع الحساب: customer (عميل عادي) أو admin (مدير)
loyalty_points نقاط الولاء المكتسبة من الحجوزات

2. جدول services (الخدمات)

الحقل الشرح
id مفتاح أساسي للخدمة
name اسم الخدمة (قص، صبغة..)
category تصنيف الخدمة
description وصف وتفاصيل الخدمة
price سعر الخدمة (DECIMAL)
duration_minutes المدة المستغرقة بالدقائق
image مسار صورة الخدمة

3. جدول employees (الموظفات)

الحقل الشرح
id مفتاح أساسي للموظفة
name اسم الموظفة المختصة
specialization تخصصها (مثال: أظافر، مكياج)
phone رقم التواصل

4. جدول appointments (الحجوزات)

الحقل الشرح
id مفتاح أساسي للحجز
customer_id مفتاح أجنبي (يربط الحجز بالعميل الذي طلبه)
service_id مفتاح أجنبي (يربط الحجز بالخدمة المطلوبة)
employee_id مفتاح أجنبي (يربط الحجز بالموظفة التي ستنفذه)
appointment_date تاريخ الحجز (DATE)
appointment_time وقت الحجز (TIME)
status حالة الحجز (pending, confirmed, completed, cancelled)

5. جدول reviews (التقييمات)

الحقل الشرح
id مفتاح أساسي للتقييم
customer_id / service_id / employee_id مفاتيح أجنبية للعميل والخدمة والموظفة المقيمة
rating التقييم من 1 إلى 5
comment نص التقييم المكتوب
is_approved هل التقييم معتمد للظهور من الإدارة؟ (0 أو 1)

5. طريقة الاتصال بقاعدة البيانات (PDO)

ربطنا المشروع بالقاعدة عبر مكتبة PDO الموجودة في PHP لأنها تحمينا من ثغرات الحقن (SQL Injection). الكود موجود في ملف includes/db.php وهو كالتالي (مخصص للتشغيل المحلي):

<?php // تعريف ثوابت الاتصال define('DB_HOST', 'localhost'); define('DB_NAME', 'beauty_salon_db'); define('DB_USER', 'root'); define('DB_PASS', ''); define('DB_CHARSET', 'utf8mb4'); // تجهيز نص الاتصال (DSN) $dsn = "mysql:host=" . DB_HOST . ";dbname=" . DB_NAME . ";charset=" . DB_CHARSET; // إعدادات الحماية وكيفية جلب البيانات $options = [ PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION, PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC, ]; try { // فتح الاتصال وتخزينه في المتغير $pdo $pdo = new PDO($dsn, DB_USER, DB_PASS, $options); } catch (PDOException $e) { die("Connection failed: " . $e->getMessage()); }

شرح الكود سطر بسطر:

define('DB_HOST', 'localhost');
نعرف ثابت باسم الخادم. في التشغيل المحلي دائماً يكون localhost.
define('DB_NAME', 'beauty_salon_db');
نضع هنا اسم قاعدة البيانات التي أنشأناها في phpMyAdmin.
define('DB_USER', 'root');
اسم المستخدم لـ XAMPP يكون افتراضياً root وكلمة المرور فارغة.
$dsn = "mysql:host=..."
نقوم بدمج المتغيرات السابقة لتكوين سطر رابط الاتصال (Data Source Name).
PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION
هذا الخيار يخبر الـ PDO بأن يظهر لنا رسالة خطأ واضحة (Exception) لو حدثت أي مشكلة بقاعدة البيانات ليسهل تتبعها.
$pdo = new PDO(...)
أهم سطر! هنا يتم إنشاء كائن الاتصال الفعلي وإرساله للمتغير `$pdo`. أي صفحة تريد تنفيذ أمر تستدعي هذا المتغير.
try { ... } catch { ... }
بلوك (المحاولة والاصطياد). نحاول فتح الاتصال داخل `try`، وإذا فشل نصطاد الخطأ في `catch` ونوقف تشغيل الموقع بدالة `die`.

6. خطوات التثبيت والتشغيل المحلي خطوة بخطوة

لتشغيل المشروع على الجهاز الخاص بكن يجب اتباع هذه الخطوات حرفياً:

  1. استلام وفك الضغط: عندما يصلكم ملف المشروع كملف مضغوط (.zip)، قوموا باستخراجه (Extract Here). سينتج مجلد اسمه Beauty-Salon.
  2. نقل الملف لمكانه الصحيح: خذوا المجلد Beauty-Salon بالكامل وقوموا بلصقه داخل مجلد السيرفر المحلي في هذا المسار: C:\xampp\htdocs\
  3. تشغيل XAMPP: افتحوا برنامج XAMPP Control Panel. اضغطوا على زر Start بجانب كل من Apache و MySQL حتى تظهر خلفيتهم باللون الأخضر.
  4. إنشاء قاعدة البيانات: افتحوا المتصفح (كروم أو ايدج) واكتبوا الرابط http://localhost/phpmyadmin. اضغطوا من القائمة الجانبية على "New". في حقل اسم القاعدة اكتبوا beauty_salon_db واختاروا ترميز `utf8mb4_unicode_ci` ثم اضغطوا Create.
  5. استيراد الجداول (Import): بعد أن تفتح قاعدة البيانات الفارغة، اضغطوا من الأعلى على تبويب Import. ثم اضغطوا على "Choose File"، واذهبوا إلى مسار مشروعنا C:\xampp\htdocs\Beauty-Salon\database\ واختاروا ملف schema.sql. انزلوا لأسفل الشاشة واضغطوا زر Import / Go لزرع الجداول.
  6. تشغيل الموقع: تم التجهيز! افتحوا المتصفح واكتبوا الرابط http://localhost/Beauty-Salon/ سيعمل الموقع معكم بنجاح.
